# Kuafu and the Sun ·《夸父逐日》

追逐落日 · Chase the setting sun.

Unity 6 · URP · **WebGPU-only** browser game (Chrome/Edge; no WebGL2 fallback).

- 在-game 风格：low-poly stylized 3D
- 角色：日纹炽热神（瘦小老人形象的太阳神）
- 大文件（FBX / 贴图 / 音频）用 Git LFS，clone 前先 `git lfs install`

## 结构

- `Assets/Characters/Kuafu/`：Tripo Unity Humanoid 绑骨 + walk，导入步骤见该目录 `README.md` 与 `CHECKLIST.md`

Unity 工程（ProjectSettings/Packages 等）在本机建好后提交到此仓库，走分支 + PR。
